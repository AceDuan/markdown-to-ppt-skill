# md-deck — Markdown → 带动画的 HTML 演示

把讲授型 Markdown 文档变成网页幻灯片：深色主题、1920×1080 自适应、Remotion 动画内嵌、单文件 HTML 可双击打开可分发。

## 必读资料（按阶段加载，不要一次全读）

- `references/content-rules.md` — 内容转换与页面设计规则。**阶段 1（大纲）前必读**。
- `references/animation-catalog.md` — 7 个动画模板的 props 与自研动画编写模式。**阶段 3（动画）前必读**。
- `references/pitfalls.md` — 已知坑与解法。**实现与 QA 期间随时对照**。

## 工程模板

`template/` 是完整可运行的 Vite + React + TS + @remotion/player 工程，包含：
导航壳（缩放舞台/键盘翻页/分步 reveal/目录/备注面板）、全部通用组件、
7 个通用动画模板（`src/animations/library/`）、单文件构建配置、示例页。

开工方式：把 `template/` **整体复制**到目标位置（如 `<课程文件夹>\slide-deck`），`npm install`，`npm run dev` 即可看到示例页在翻。所有后续工作都在这个副本里进行。

## 工作流（六阶段，两个强制确认门）

### 阶段 0 · 输入分析
- 通读用户的一篇或多篇 Markdown。多文档时先归组（按标题层级/主题），拿不准就问一句。
- 只问最少的问题，均有默认值：①用途与受众（默认：课堂讲授）②是否需要讲稿备注（默认：要）③有无现场演示环节（默认：无，不生成演示徽标页）。
- 判断领域与"贯穿性概念"（最多 3-4 个，将获得固定强调色，见 content-rules.md）。

### 阶段 1 · 大纲（🚪 门 1，未经确认不得写页面）
- 先读 `references/content-rules.md`。
- 产出 `<主题>-幻灯片大纲.md` 放到用户项目路径下，包含：
  ① 总体设计（主题色系统、页面节奏、交互约定）② 动画清单（编号 AN-xx、对应章节、内容、交互方式）
  ③ 逐页大纲（每页标题 + 要点 + 用哪个动画/图表，标注【扩充】）④ 待确认项。
- 页数与节奏要给用户留删减空间；扩充内容必须显式标注。
- **等用户确认/批注后才能进入阶段 2。**

### 阶段 2 · 脚手架（🚪 门 2）
- 复制 `template/` → `npm install` → `npm run dev`。
- 按大纲把 chapters 和全部页面注册进 `src/deck.tsx`（未实现的用内置 `ph()` 占位）。
- 实现封面、章节封面、个别概念页作为样式样章。
- 让用户翻一遍空壳确认导航手感与样章样式，再继续。

### 阶段 3-4 · 分批实现
- 内容页：数据驱动、按大纲逐页实现；每章 = 章节封面 → 概念页（分步）→ 动画页 → 小结卡。
- 动画：先查 `references/animation-catalog.md` 用模板；没有合适的再按其中的"自研模式"写；写完立刻在浏览器里验证关键帧。
- **每批完成后必须截图自查再交给用户**（方法见 pitfalls.md 的 QA 小节）。

### 阶段 5 · 全量走查
- 全部页面按"分步展开完成"状态逐页截图（分批跑，防超时）逐张检查；发现问题修复并复验。
- `npm run typecheck && npm run build` 必须全绿。

### 阶段 6 · 构建交付
- `npm run build` → 产物 `dist/index.html` 是**单文件**（全部内联），复制到用户项目路径、起好记的名字（如 `<主题>-课件.html`）。
- 验证构建产物：`npm run preview` 后在浏览器里翻几页、放一个动画、试一次点击翻页。
- 生成/更新 README（快捷键、如何改内容、如何加页加动画）；如用户需要，附"编辑模式启动脚本"（bat）。

## 硬性规则

1. **门 1 的大纲未经用户确认，不得开始写任何页面代码。**
2. 一页一个观点；1080p 基准正文字号 ≥ 28px；笔记表格禁止直接上屏（重设计为大字卡/标尺/分步表）。
3. 动画宁缺毋滥——只给"必须看着发生才懂"的概念；页面内第一组内容不包 Reveal（进页即可见）。
4. 每批交付前先自查截图，把明显问题清零再交。
5. 单文件构建后必须在浏览器实测（翻页 + 动画 + 点击），不能只看 build 成功。
6. 笔记中的更正/口误/来源类信息只进 `notes`，不上屏。

## 常见变更

- **改主题色**：`src/styles.css` 的 CSS 变量（--accent 与三个贯穿色）。
- **加一页**：`slides/` 写组件 → `deck.tsx` 加一条记录（含 notes）。
- **加动画**：优先复用 library 模板；自研照 animation-catalog.md 的模式。
- **改完重新出单文件**：`npm run build` → 复制 `dist/index.html`。
