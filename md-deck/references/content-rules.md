# 内容转换与页面设计规则（阶段 1 大纲前必读）

> 核心原则：**Markdown 是原材料，不是幻灯片。** 直接把笔记贴进页面必然失败——
> 要按课堂讲授的节奏重新设计，并让用户在大纲门确认。

## 1. 从笔记到大纲

1. **归组**：多篇文档先合并归组（按标题层级、主题相关性）；每章对应笔记的一个大主题。
2. **节奏模板**：每章固定为 `章节封面 → 概念页（分步）→ 动画页 → 小结卡`，学生形成预期。
3. **一页一观点**：把笔记的段落拆成页；一页讲不完的就拆，不要缩字号。
4. **悬念页**：章节衔接处可以放一页大字问题（如"到底能不能 X？"），下一章开头回答。
5. **【扩充】标注**：笔记之外新增的内容（开场钩子、直觉标尺、自测题、类比）在大纲里全部标【扩充】，用户可删。
6. **更正隔离**：笔记里"口误已更正 / 字幕误写 / 严格来说是…"类信息**只写进该页 notes**，永不上屏。
7. **页数量级**：全日课程（2h+）约 80-100 页；单场分享 30-50 页。给用户留删减空间。

## 2. 页面设计规范

- **画幅**：1920×1080 设计基准，整体缩放适配；正文 ≥ 28px、行高 1.5-1.7，投影可读优先。
- **配色**：深底浅字；为贯穿全课的 2-4 个核心概念分配固定强调色（theme 的 --accent-1/2/3，
  可按领域改名），总结页用同色系收束形成回扣。辅助色：提示=绿、警告=橙红、信息=蓝。
- **页面类型**：封面 / 章节封面（SectionDivider）/ 概念页 / 动画页 / 对比卡 / 标尺图 / 表格页 /
  Callout 页 / 小结卡。每种都有现成组件，不要发明新样式。
- **表格改造**（笔记表格禁止直接上屏）：
  - ≥3 行的概念对照 → `kv` 表 + 分步出现，或拆成多张大字卡；
  - 数值分布 → RulerChart 标尺；
  - 方案对比 → GrowBars 或双卡对比；
  - 一句话能说的 → Callout。
- **分步 reveal**：`<Reveal order={n}>`；**第一组内容不包 Reveal**（进页即可见，避免全黑页）；
  页面 steps 数与 Reveal 最大 order 一致。
- **Callout 三型**：tip=绿（要点/实操）、warning=橙红（误区/警告/边界）、info=蓝（补充/对照）。
- **公式**：KaTeX（`<Formula tex={String.raw`...`} />`），一页最多一个公式块。
- **文字风格**：短句、动词开头、关键名词加粗；同一概念全 deck 用同一个词。

## 3. 动画分配原则（在大纲阶段就要决定）

- 只给"必须看着发生才懂"的概念做动画；先查 animation-catalog.md 的 7 个模板能否覆盖。
- 大纲里给每个动画编号（AN-01…）+ 一句话内容 + 交互方式（切换/滑块/自动循环）。
- 静态能讲清的用 SVG/对比卡——宁缺毋滥，动画是教学内容本身，不是转场装饰。
- 有现场演示环节（软件/实验）的概念：页面放 `LabBadge` 徽标提示切换时机，
  幻灯片只承载"设计→结果"的承接。

## 4. 讲稿备注（notes）

- 每页都要写 notes：这页讲什么、强调什么、衔接下一页的话头。
- 更正/来源/严格术语辨析/课堂管理提醒 全部放这里。
- 用户在放映时按 N 可见当前页 + 下一页的备注。
