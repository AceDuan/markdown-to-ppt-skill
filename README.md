# md-deck — Markdown → 带动画的 HTML 演示（ZCode Skill）

把一篇或多篇 Markdown 笔记/文档，制作成**带 Remotion 动画的网页幻灯片**：
深色主题、1920×1080 自适应、浏览器全屏授课、**单文件 HTML 可双击打开、可分发**。

## 目录结构

```
skill\
├── README.md                  ← 本文件
└── md-deck\                   ← skill 本体（安装时把这个文件夹复制过去）
    ├── SKILL.md               # 触发条件 + 六阶段工作流（skill 入口）
    ├── references\
    │   ├── content-rules.md       # 内容转换与页面设计规则
    │   ├── animation-catalog.md   # 7 个动画模板文档 + 自研动画模式
    │   └── pitfalls.md            # 实战坑清单（布局/动画/构建/QA）
    └── template\                  # 完整可运行的 Vite + React + TS 工程
        ├── package.json / vite.config.ts / tsconfig.json / index.html
        ├── dev.bat                    # 双击启动开发模式（Windows）
        └── src\
            ├── App.tsx                # 导航壳：缩放舞台/键盘翻页/目录/备注面板
            ├── deck.tsx               # 幻灯片注册表（整个 deck 的唯一事实来源）
            ├── styles.css             # 主题变量（改这里全局换肤）
            ├── components\            # 通用组件（Reveal 分步 / FigureFrame 动画容器 / 卡片 Callout 公式…）
            ├── slides\                # 页面组件（示例页，替换成真实内容）
            └── animations\library\    # 7 个通用动画模板
```

## 安装

把 `md-deck` 文件夹整个复制到 ZCode 的技能目录（任选其一）：

- 用户级（所有项目可用）：`C:\Users\<你>\.zcode\skills\md-deck`
- 项目级（仅当前项目）：`<项目>\.zcode\skills\md-deck`

## 怎么用

安装后，在对话里直接说：

- 「把这篇笔记做成带动画的幻灯片/课件」
- 「根据这两篇 markdown 做一个可演示的 HTML」
- 「我想给我的教程做一个双击就能打开的网页演示」

Skill 会按六阶段推进：

| 阶段 | 发生什么 | 你要做什么 |
| --- | --- | --- |
| 0 输入分析 | 读文档、归组、确认用途受众 | 回答最少的问题（都有默认值） |
| 1 大纲 | 产出逐页大纲 md（页面结构、动画清单、配色、扩充项） | **审阅并确认**（门 1，可批注删改） |
| 2 脚手架 | 复制工程模板、注册全部页面（先占位）、做样章 | 翻一遍空壳确认导航手感（门 2） |
| 3-4 分批实现 | 内容页 + 动画分批写，每批截图自查后交你过目 | 分批提修改意见 |
| 5 全量走查 | 全部页面逐页截图检查、修复、typecheck/build | — |
| 6 构建交付 | 产出**单文件 HTML** + 使用说明 | 双击验收 |

## 产物

1. **可编辑工程**（`slide-deck/`）：改文字、改动画都在这里，`npm run dev` 热更新。
2. **单文件课件**（`<主题>-课件.html`，约 2-3 MB）：所有页面/动画/字体内联在一个 HTML 里，
   **双击即开、离线可用、可拷 U 盘、可发学生**。改完工程后 `npm run build` 重新生成。
3. （可选）编辑模式启动脚本（bat）。

## 操作（放映时）

| 按键 | 行为 |
| --- | --- |
| ← / → / 空格 / 点击 | 翻页；页内有分步内容时先逐步展开 |
| F | 全屏 |
| G | 目录总览（点击跳页） |
| N | 讲稿备注面板（当前页 + 下一页） |

## 动画模板（7 个）

| 模板 | 用途 |
| --- | --- |
| GrowBars | 增长条形对比（方案对比、容量/性能） |
| FlowChain | 流程链逐节点点亮 |
| RulerChart | 横向标尺/分布条（线性/对数、彩色区段） |
| DualCurve | 双曲线对比（线性 vs 对数等） |
| Staircase | 量化阶梯（连续→离散 + 误差带） |
| ParticleDrift | 粒子漂移聚散（场函数驱动，图案重组） |
| DualView | 双视角：组合 ↔ 分解（时域↔频域类） |

每个都是参数化的 React 组件（换 props 即换数据）；覆盖不了的动画按
`references/animation-catalog.md` 里的自研模式现写。

## 定制主题

改 `src/styles.css` 顶部的 CSS 变量：`--accent`（主强调色）+ 三个贯穿色
`--accent-1 / --accent-2 / --accent-3`（按你的领域语义改名，如"指标A/指标B/指标C"）+ 字体。

## 适用边界

- ✅ 课程笔记、技术分享、培训材料等**讲授型**文档（单篇或多篇）。
- ❌ 交付物必须是 .pptx 的场景（本 skill 产出 HTML；PPT 管线是另一个话题）。
- ❌ 纯文学/散文类内容（没有"讲授结构"可提取）。
- 动画深度定制的质量取决于大纲确认时的沟通——模板保证工程与版式，动画的"对不对味"需要你在门 1 把关。
